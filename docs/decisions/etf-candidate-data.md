# ETF 후보 데이터 관리 방식

## Decisions

- 후보 ETF 목록은 사람이 직접 적어 코드에 올려 둔 정적 데이터로 관리한다. 순자산·총보수를 실시간으로 조회해 후보를 자동으로 고르는 외부 API를 쓰지 않는다.
- 후보는 국내 상장 ETF만 다룬다. 해외 거래소에 직접 상장된 종목은 대상이 아니다.

## Boundaries

- 이 결정은 "추천에 올릴 후보를 무엇으로 채우는가"에만 적용된다. 보유 종목의 전일 종가를 가져오는 것처럼 이미 산 자산의 가격을 확인하는 기능은 다른 문제이고, 이 결정이 그 기능의 데이터 소스까지 정하지 않는다.
- 후보를 늘리거나 갈아 끼우는 일은 코드를 고쳐 새 버전을 내는 것으로 한다. 화면에서 후보를 추가·수정하는 기능은 이 결정의 범위 밖이다.

## Why

이 앱은 본인 한 사람이 쓰는 개인 도구다. 후보군이 매일 바뀔 필요가 없고, 무료로 믿을 만한 국내 ETF 스크리닝 API를 구하는 것부터 쉽지 않다. 정적 목록은 구현이 간단하고, 어떤 종목이 왜 후보에 있는지 코드만 보고 바로 알 수 있다.

실시간 조회는 매력적으로 보이지만 이 프로젝트 규모에서는 실익보다 API 키 관리, 요청 실패 처리, 데이터 신뢰성 검증 같은 부담이 더 크다.

## Reconsider when

- 후보 목록을 자주 갈아야 할 이유(예: 실제로 여러 사람이 쓰게 되어 각자 다른 후보가 필요해짐)가 생길 때
- 무료로 쓸 수 있고 신뢰할 만한 국내 ETF 데이터 API가 검증될 때

## Still-rejected alternatives

- 외부 API로 순자산·총보수를 실시간 조회해 후보를 자동 산출하는 방식 — 개인 도구 규모에 비해 구현 부담이 크고, 무료 국내 ETF 데이터 API의 신뢰성이 검증되지 않았다.

## Evidence worth preserving

- 2026년 9월 기준 조사에서 "ARIRANG" ETF 브랜드가 "PLUS ETF"로 이름이 바뀐 것을 확인했다. 브랜드명은 바뀔 수 있으므로 후보 데이터는 종목코드를 우선 식별자로 삼고, 상품명은 참고용으로 둔다.
