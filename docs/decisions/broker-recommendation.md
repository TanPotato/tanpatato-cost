# 실행 안내의 증권사 추천

## Decisions

- 실행 안내는 미래에셋증권 M-STOCK 하나만 고정으로 추천한다. 여러 증권사 중 고르는 선택지는 주지 않는다.
- 계좌 개설 안내 문구는 M-STOCK 앱의 실제 진입 경로("메뉴 > 서비스 > 계좌개설")를 담는다.

## Boundaries

- 이 결정은 이미 다른 증권사 계좌가 있는 사용자를 대상으로 하지 않는다. 처음 계좌를 트는 사람을 기준으로 삼는다.
- 실제 매매 실행이나 증권사 API 연동은 다루지 않는다. 설치부터 주문까지 사용자가 직접 따라 할 절차를 안내하는 데까지다.

## Why

M-STOCK은 초보 투자자에게 직관적인 UI로 알려져 있고, 비대면 계좌 개설을 24시간 앱 안에서 마칠 수 있다. 추천 종목 중 두 개(TIGER 200, TIGER 미국S&P500)가 미래에셋자산운용의 상품이라, 같은 회사 앱에서 사는 흐름이 자연스럽다. 여러 증권사를 후보로 제시하면 이후 단계 안내가 증권사별로 갈라져 범위가 크게 늘어난다.

## Reconsider when

- 이미 다른 증권사 계좌가 있는 사용자를 위한 대안 경로가 필요해질 때.
- M-STOCK의 화면 구성이나 메뉴 경로가 바뀌어 안내 문구가 실제와 어긋날 때 — 이 앱이 통제할 수 없는 외부 서비스 변경이라, 발견 즉시 사람이 직접 문구를 고치는 것이 잠정 대응이다.

## Still-rejected alternatives

- 토스증권 — 처음 제안했던 후보였으나, 사용자가 "미래에셋증권"으로 명시적으로 바꿨다.
