# 보유 종목 기록의 범위

## Decisions

- 보유 종목은 티커 제한 없이 어떤 국내 상장 종목이든 기록할 수 있다. [etf-candidate-data](etf-candidate-data.md)의 6개 후보에 한정하지 않는다.
- 종목명은 사용자가 직접 입력하지 않고, 티커를 근거로 자동 조회해 채운다.
- 종목별로 평균 매수단가 하나만 기록한다. 여러 시점·다른 가격에 나눠 산 이력은 관리하지 않는다.

## Boundaries

- 이 결정은 "이미 산 것을 어떻게 기록하는가"에만 적용된다. 추천에 올릴 후보를 무엇으로 채우는지는 [etf-candidate-data](etf-candidate-data.md)가 따로 정한다.

## Why

이 화면은 사용자가 실제로 산 것을 있는 그대로 기록하는 곳이다. `PRODUCT.md`의 "개별 종목은 추천하지 않는다"는 추천 엔진의 범위이지, 이미 산 것을 기록하는 이 기능의 범위가 아니다. 종목명을 직접 입력받으면 오탈자나 브랜드명 변경(예: ARIRANG → PLUS ETF, [etf-candidate-data](etf-candidate-data.md)의 Evidence 참고) 위험이 있어, 더 안정적인 식별자인 티커로 조회해 채운다.

## Still-rejected alternatives

- 추천받은 3종목만 기록하게 제한하는 방식 — 사용자가 실제로 산 다른 종목을 기록할 길이 없어져, "실제로 산 것을 기록한다"는 목적과 부딪힌다.

## Evidence worth preserving

- 종목당 평균 매수단가 하나만 기록하므로, 실제로는 여러 번에 걸쳐 다른 가격에 산 경우 화면의 매입금액·수익률이 사용자가 직접 계산한 평균의 정확도에 좌우된다. 분할 매수 이력 관리가 필요해지면 이 전제부터 다시 봐야 한다.
